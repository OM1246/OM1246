## 💫 About Me

I is a driven **Computer Engineering student** with a deep specialization in **Artificial Intelligence** and **Machine Learning**. My passion lies in bridging the gap between complex theoretical models and functional, real-world applications. 

Currently, I am focused on:
* 🧠 **Deep Learning:** Building and optimizing Convolutional Neural Networks (CNNs) and exploring predictive modeling using **TensorFlow**, **Keras**, and **PyTorch**.
* ⛓️ **Blockchain Development:** Developing Decentralized Applications (DApps) and exploring the Web3 ecosystem using **Web3.js** and smart contract technologies.
* 💻 **Full-Stack Engineering:** Crafting seamless user experiences with **Node.js**, **Vue.js**, and **Next.js**, while maintaining robust backends with **Django** and **PostgreSQL**.
* 🎨 **Creative Tech:** Merging code with creativity using tools like **Blender** and **Adobe Creative Cloud** to visualize data and design intuitive interfaces.

I am always looking to collaborate on research-oriented projects or innovative hackathons that challenge the status quo.
